# @forkbomb/pio-mcp

Functional alias for [platformio-mcp](https://github.com/jl-codes/platformio-mcp). It delegates CLI commands and MCP stdio to the exact canonical package version; it does not download an alternate implementation or run install scripts.

This package is a release candidate, not evidence that the npm scope is controlled or the name has been published. Verify publication in the distribution inventory before using it.
