Privacy policy

Effective October 1, 2026. Publisher: Tony Loehr. For privacy questions, use the support page.

Data used for your request

PIO Agent runs on your computer. It reads the PlatformIO projects and device information needed for the operation you request. Depending on the operation, that can include project paths and configuration, source-file names and content, connected-device identifiers, build and test output, serial output, task history, approval records, and diagnostic artifacts.

Its dashboard is served locally. PIO Agent does not require a publisher account, and the distributed local runtime does not send analytics or project data to a PIO Agent publisher service.

Local storage and retention

PIO Agent stores task, audit, automation, and diagnostic records locally, primarily in each project's .pio-mcp-workspace/ directory or a data directory you configure. Most records remain until you delete them; removing the plugin does not erase project files or local evidence. Some managed temporary artifacts have shorter lifetimes, including a 24-hour managed core-dump retention path.

You control the local project and data directories and can delete them after stopping active tasks. Deletion may remove history needed to investigate past hardware actions.

Recipients and external services

When you use PIO Agent through Codex or another MCP host, that host receives tool inputs and outputs needed to answer your request. The host's own privacy policy and settings govern its handling of those messages. PlatformIO Core and package registries may receive requests when you choose operations that install or update platforms, packages, or libraries; their policies govern those services.

PIO Agent does not sell personal data or share local project data with advertisers. It does not seek payment-card data, health data, government identifiers, passwords, API keys, or other secrets. Do not put them in project paths, serial logs, issue reports, or tool inputs. The runtime redacts known secret patterns and bounds logs, but review content before sharing it outside your computer.

This website is hosted by GitHub Pages, and support requests use GitHub Issues. GitHub may process connection and issue data under its own privacy statement.

Your controls

To inspect or remove locally stored data, look in the relevant project's .pio-mcp-workspace/ directory and any configured PIO Agent data directory. For requests about publisher-controlled information or this policy, use the support page. Material changes to these practices will be reflected here with a new effective date.
