Support

PIO Agent is an open-source local PlatformIO tool published by Tony Loehr.

Get help

For installation problems, bug reports, and feature requests, open a GitHub issue. Include your operating system, Codex version, PIO Agent version, attempted operation, and a short redacted error.

Do not post credentials, private source code, unredacted serial output, device identifiers, or one-time dashboard links. For a security-sensitive report, ask for a private reporting channel in an issue without posting exploit details or secrets.

Self-service guides

The Codex installation guide covers prerequisites, updates, removal, and rollback. The agent field guide describes capabilities and permissions.
